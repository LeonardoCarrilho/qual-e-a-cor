# 🎨 Qual é a cor?

Gerador de cores aleatórias para descobrir cores CSS, feito com **HTML, CSS e JavaScript**.

🔗 **Ao vivo:** https://leonardocarrilho.github.io/qual-e-a-cor/

## Funcionalidades
- Três modos: nomes de cores CSS, hexadecimal e RGB
- Botão para copiar o código da cor
- Histórico das últimas 8 cores

## Como rodar
Abra o `index.html` no navegador.

Projeto do módulo 17 do curso Full Stack Turbo (TipsCode), com o modo RGB, a cópia e o histórico adicionados.
